Dataset Access for QATNet

Due to GitHub file size limitations, the datasets used in the QATNet (Q=5) experiments are hosted externally on Google Drive.

OD-IDS2022 (Cleaned Dataset)  
Download link:  
https://drive.google.com/file/d/1-wcRGvfMy3HZoViWSHRdJcvH8qARYHRT/view?usp=sharing

Expected filename:  
OD10cleaned_intrusion_dataset.csv

CIC-IDS2018 (Cleaned & Sampled Dataset)  
Download link:  
https://drive.google.com/file/d/1gF4dwwP3r2uOeUIz7IQDu7M18VCJZ3ds/view?usp=sharing

Expected filename:  
cleaned_data_sampled_2018.csv

After downloading, place each CSV file in the same directory as its corresponding Jupyter notebook, or update the file path in the notebook accordingly.

Note: Dataset usage is subject to the original dataset licenses and terms of use.
